# NET009-0000183 Link-Label Correction

## Change

The stimulus table previously labeled its four proposed links as A, B, C, and D.
Because the quiz engine can shuffle answer choices and then assign new A-D display
labels, those table identifiers could conflict visually with the displayed answer
letters.

The stimulus now uses Link 1, Link 2, Link 3, and Link 4. All answer choices and
explanations were updated to use the numbered identifiers.
